# EasyLoad Pro — د حسابونو او ګټې اپلیکیشن

دا نسخه یوازې د Easyload دوکان د معاملاتو، خرڅلاو، ګټې او پورونو د ثبت لپاره ده. مستقیم کریډیټ نه لېږي او API ته اړتیا نه لري.

## امکانات
- Roshan، AWCC، Etisalat، MTN/ATOMA او Salaam
- د هرې معاملې ثبت، د ګټې سلنه او اتومات محاسبه
- د مشتری نوم، شمېره او پاتې پور
- د معاملاتو تاریخچه
- ورځنی او ټول خرڅلاو/ګټه
- د شبکو جلا راپور او CSV صادرول
- په براوزر کې محلي ساتنه او PWA آفلاین ملاتړ

## د Android نصب
1. ZIP فایل خلاص کړئ او فایلونه GitHub repository ته پورته کړئ.
2. GitHub کې Settings → Pages ته لاړ شئ او Deploy from branch فعال کړئ.
3. د Pages لینک په Android Chrome کې خلاص کړئ.
4. د Chrome له مینو څخه Install app یا Add to Home screen وټاکئ.

## د معلوماتو ساتنه
معلومات په هماغه موبایل او براوزر کې ساتل کېږي. د براوزر ډاټا پاکول معلومات له منځه وړلی شي؛ د بیک اپ لپاره د CSV صادرول وکاروئ.
